# ermoluk/homebrew-tap

Homebrew formulae for [mcp-warden](https://github.com/ermoluk/mcp-warden), a
local-first credential broker for the Model Context Protocol.

```bash
brew install ermoluk/tap/mcp-warden
```

The formula installs the prebuilt release binary for macOS (arm64, x86_64) or
Linux (x86_64, arm64; static musl builds) and checks it against the release's
SHA-256. The mcp-warden release workflow updates it on every release; it never
updates itself.
